# What tests/Wiring.lean cannot tell from the code: which definitions a
# law states running code against, what is assumed, which mirrors are
# proven equal to running code, and what would make each model real.
# One note a line: a kind, a name, and text.
#
#   entry NAME           an entry point besides `main` and the runner: an
#                        `@[export]` a shipping platform calls
#   spec NAME TEXT       a specification laws state running code against.
#                        Not a subject (it must not run); of what it names,
#                        what runs is.
#   assume NAME TEXT     an assumption: a hypothesis the laws take, or a
#                        model of something the running code is generic
#                        over (the store, the cryptography). Not a subject.
#                        TEXT `= OTHER` makes NAME part of OTHER's.
#   bridge MIRROR LAW    LAW, audited, proves the running code equal to
#                        MIRROR, so laws about MIRROR are about it
#   todo NAME TEXT       what would make the laws about NAME, which does
#                        not run, about running code. The README's todo
#                        rows follow this file's order; `= OTHER` puts
#                        NAME in OTHER's row.
#   subject LAW NAMES    LAW's subject is NAMES (its statement must name
#                        each), where the heuristic takes too much
#   wired LAW            LAW must be wired; the check fails if it is not

## Assumptions

assume Community.Unforgeable An Ed25519 signature that verifies under a device key was made by that key's holder.
assume Engine.CollisionFree SHA-256 has no collision among the ops a node received.
assume Engine.Distinct = Engine.CollisionFree
assume Community.Merkle.NoSecondPreimage SHA-256 has no second preimage on a file's Merkle tree inputs.
assume Connection.Noise.Suite.Good X25519 agrees, the AEAD opens what it seals, and public keys are 32 bytes (correctness only).
assume Connection.Keys.Good A device's Ed25519 key converts to its seed's X25519 key.
assume Community.Seal.Good The seal's AEAD and key wrap open what they seal (correctness only).
assume Connection.Noise.Symbolic.sym The symbolic model of the cryptography: the running handshake over a suite of symbols, where only a key's holder can derive what it guards.
assume Engine.Model.run The store model: the SQLite store's reads and writes answer as the model's tables (`DB`), and a held store's (`Held`) do too. Tested, not proven: SQLite against the model (tests/engine/Differential.lean) and list queries against their meaning (tests/engine/QueryDiff.lean).
assume Engine.eval = Engine.Model.run
assume Engine.matching = Engine.Model.run
assume Engine.DB.empty = Engine.Model.run
assume Engine.budget = Engine.Model.run
assume Engine.Sync.HeldM.run = Engine.Model.run
assume ArrivalLaws.modelReads = Engine.Model.run
assume ArrivalLaws.readsOf = Engine.Model.run
