# Laws over models: the laws tests/Wiring.lean classes `model` (they
# name a definition nothing that runs calls, or nothing of this
# repository's code at all), as of origin/main 59fa463 (2026-11-01).
#
# The rule (AGENTS.md): a law is about running code, or about a model
# that a `bridge` law proves equal to running code. This list only
# shrinks:
# - tests/Wiring.lean fails on a model law it does not name: state the
#   law over the code that runs, or bridge its model (tests/wiring.txt);
# - it fails on a name here that is no longer a model law (ported,
#   bridged, a World or control law, or gone): delete the line
#   (ci/proof-links.py --prune does);
# - ci/proof-links.py --check fails on a name the merge base with
#   origin/main did not list. A renamed law keeps its line as
#   `NEW  # was OLD`.
#
# One law per line, grouped by module.
